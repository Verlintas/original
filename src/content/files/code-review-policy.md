A code review policy template covering who reviews, required approvals, author and reviewer responsibilities, a review checklist, merge rules, stale pull requests, and escalation.

## USE

- Set approval counts to match the team size.
- Make the checklist specific to the project risks.
- Explain how disagreements are resolved.

## NOTES

- Review the change, not the author.
- Keep optional comments clearly marked so blocking issues are obvious.
