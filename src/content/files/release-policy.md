A release policy template: semantic versioning, cadence, changelog rules, a release checklist, artifact signing, support windows, and deprecation.

## USE

- Pick a cadence the team can actually sustain.
- Publish checksums and signatures with every artifact.
- Keep release tags and old artifacts available.

## NOTES

- Semantic versioning only works if the public API is defined.
- SBOMs and signed artifacts are increasingly expected by users and regulators.
