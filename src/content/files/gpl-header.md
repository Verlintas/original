The notice recommended by the GNU project for source files released under
GPLv3, adapted from the "How to Apply These Terms" appendix.

## USE

- Paste the notice at the top of each source file and fill in the program
  name, year and author.
- Keep the full license text in `COPYING`.
- Remove the "or any later version" sentence to license under GPL-3.0-only.

## NOTES

- The GNU project recommends including the full notice in interactive
  programs so they display it on startup.
- SPDX identifiers: `GPL-3.0-or-later` or `GPL-3.0-only`.
