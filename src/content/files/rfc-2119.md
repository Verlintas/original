The document that gives technical writing its requirement keywords: MUST, MUST NOT, REQUIRED, SHALL, SHALL NOT, SHOULD, SHOULD NOT, RECOMMENDED, MAY, and OPTIONAL. Read it with RFC 8174.

## USE

- Use uppercase keywords only where the requirement is normative.
- Cite as RFC 2119 (BCP 14).
- Read with RFC 8174 for the uppercase/lowercase rule.

## NOTES

- Updated in interpretation by RFC 8174.
- Status: Best Current Practice.
