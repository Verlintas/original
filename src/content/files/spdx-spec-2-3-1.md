The SPDX specification defines a machine-readable format for software bills of materials, license identifiers, and package metadata. This entry links to the canonical 2.3.1 specification rather than mirroring a large HTML document.

## USE

- Use SPDX identifiers in package metadata and source headers.
- Use SPDX license expressions for compound licensing.
- Read the annexes for license matching and expression syntax.
