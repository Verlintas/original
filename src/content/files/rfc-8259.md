The Internet Standard for JSON, replacing RFC 7159. It defines the grammar, the value types, character encoding, and the interoperability rules that parsers and generators should follow.

## USE

- Use as the normative reference for JSON syntax.
- Require UTF-8 for interchange.
- Reject duplicate names or define a policy for them.

## NOTES

- Internet Standard STD 90.
- Obsoletes RFC 7159 and RFC 4627.
