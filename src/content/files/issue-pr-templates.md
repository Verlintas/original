A small pack of GitHub templates: a bug report form, a feature request form, a pull request checklist, and a config file linking the code of conduct and security policy.

## USE

- Create the files under `.github/ISSUE_TEMPLATE/` and `.github/`.
- Adjust labels, fields, and the repository URL placeholders.
- Keep forms short; every required field must earn its place.

## NOTES

- YAML issue forms are supported by GitHub and render as structured forms.
- Link security reporting privately rather than through public issues.
