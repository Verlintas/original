One stylesheet that turns any page red on white: the same palette, the same hairline
rules, the same cap-height circle as this site. Drop it into a page and the page
becomes Original.

## ABOUT THIS FILE

- CSS custom properties for the full palette.
- The circle mark as a plain CSS class — no image required.
- No dependencies; works in any browser made this century.
