Semantic Versioning gives version numbers meaning: MAJOR for incompatible changes, MINOR for backward-compatible features, PATCH for backward-compatible fixes. This is the canonical 2.0.0 specification.

## USE

- Use MAJOR.MINOR.PATCH for public APIs.
- Increment MAJOR for breaking changes.
- Document pre-release and build metadata.
