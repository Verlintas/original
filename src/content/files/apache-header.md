The per-file notice for projects licensed under Apache 2.0, taken from the
license's own appendix, together with notes on NOTICE files and the ASF
variant.

## USE

- Paste the notice at the top of each source file.
- Replace `[yyyy]` and `[name of copyright owner]`.
- Keep the full license text in `LICENSE`; keep `NOTICE` if present.

## NOTES

- The ASF variant (for Apache Software Foundation projects) differs; the
  general form in this file is the correct one for independent projects.
- Machine-readable identifier: `SPDX-License-Identifier: Apache-2.0`.
