A short update to RFC 2119 that removes an ambiguity: the requirement keywords are normative only when they appear in uppercase. It is part of BCP 14.

## USE

- Apply the uppercase rule when writing specifications.
- Cite as RFC 8174 (BCP 14).
- Do not treat lowercase uses as normative requirements.

## NOTES

- Updates RFC 2119.
- Status: Best Current Practice.
