A governance document template: roles from users to maintainers, lazy consensus and voting, adding and retiring maintainers, conflicts of interest, and amendments.

## USE

- Describe how the project actually decides things today.
- Fill in maintainer and contributor files and link them.
- Review the document when the project size changes materially.

## NOTES

- Governance should reduce ambiguity, not add ceremony.
- Adapted from common open source governance patterns.
