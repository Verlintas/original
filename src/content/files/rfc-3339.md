RFC 3339 defines the date and time format used across the internet, including the `YYYY-MM-DDTHH:MM:SSZ` timestamps in JSON, feeds, and logs.

## USE

- Use an offset or `Z` so a timestamp is unambiguous.
- Prefer UTC for machine-readable timestamps.
- Cite RFC 3339 when defining an API field.

## NOTES

- Profile of ISO 8601.
- The RFC also defines the `date-time` format used by JSON Schema.
