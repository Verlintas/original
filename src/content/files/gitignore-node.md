GitHub’s official Node.js .gitignore template. It is maintained in GitHub’s public template collection and released under CC0-1.0.

## USE

- Copy it to the repository root as `.gitignore`.
- Merge it with project-specific patterns; later patterns take precedence.
- Commit the result so every contributor uses the same rules.

## NOTES

- The template is a starting point; remove patterns you do not need.
- Generated files should usually stay untracked.
