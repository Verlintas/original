A security policy template for SECURITY.md: supported versions, private reporting channels, response targets, coordinated disclosure, safe harbour, and out-of-scope items.

## USE

- Publish as SECURITY.md and enable private vulnerability reporting.
- Fill in real response targets and a monitored contact.
- Pair it with a security.txt file (FILES → POLICIES).

## NOTES

- Safe harbour language should be reviewed for your jurisdiction.
- Keep the support table current; stale versions undermine the policy.
