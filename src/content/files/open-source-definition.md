The Open Source Definition is the OSI’s canonical test for an open-source license: free redistribution, source code, derived works, integrity, no discrimination, and technology neutrality.

## USE

- Use it to test whether a license qualifies as open source.
- Cite the ten criteria, not just the label “open source”.
- Read the license itself before applying the label.
