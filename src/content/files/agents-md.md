A template for AGENTS.md, the README for coding agents. It gives an agent the shortest path to a correct change: how to set up, build, test, where things live, what not to touch, and when to stop and ask.

## USE

- Place at the repository root and keep it current.
- Replace every placeholder with commands that actually work.
- State agent boundaries explicitly: may edit, ask first, never.

## NOTES

- Outdated instructions are worse than none; review on release.
- Follows the community AGENTS.md convention.
