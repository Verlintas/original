A practical checklist for deciding whether an agent is ready for real work. It evaluates the whole loop: model, tools, prompts, and environment, with explicit pass criteria and a regression suite.

## USE

- Replace targets and scales with values that fit the task.
- Use real tasks, not benchmark trivia.
- Turn every real failure into a regression test.

## NOTES

- Measure failure modes, not just averages.
- Keep the evaluation suite versioned with the agent.
