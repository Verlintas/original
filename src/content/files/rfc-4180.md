The widely cited specification for comma-separated values. It defines the common format, quoting rules, line breaks, and the text/csv media type. It is informative rather than an Internet Standard, but it is the reference most tools follow.

## USE

- Quote fields that contain commas, quotes, or line breaks.
- Double embedded quotes inside quoted fields.
- Use CRLF line endings when strict interoperability matters.

## NOTES

- Informational RFC, not an Internet Standard.
- Real-world CSV often varies; validate against the producer.
