The core syntax reference for URIs. It defines the components, percent-encoding, resolution, and normalization rules that URL parsers and APIs depend on.

## USE

- Use it when parsing or constructing URLs by hand.
- Percent-encode reserved characters correctly.
- Do not confuse a URI with a URL or an IRI.

## NOTES

- Obsoletes RFC 2396.
- See RFC 3987 for internationalized resource identifiers (IRIs).
