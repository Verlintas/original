The specification for security.txt, a machine-readable file at /.well-known/security.txt that tells researchers how to report vulnerabilities. This site publishes one.

## USE

- Publish at /.well-known/security.txt.
- Include Contact and Expires fields.
- Sign the file if you need to prove authenticity.

## NOTES

- The Contact field is required.
- The Expires field is required and must be in the future.
- See also this site’s security.txt.
