Creative Commons licenses require attribution. A useful memory aid is **TASL**.

## TASL

- **T**itle — the name of the work
- **A**uthor — who made it
- **S**ource — where you found it
- **L**icense — which CC license, with a link

Example:

> “A photograph of a red door” by Alex Example, via Wikimedia Commons, licensed CC BY 4.0. Cropped and resized.

## IF YOU CHANGE IT

Say what you changed: cropped, translated, remixed, color-corrected. If the license is NoDerivatives, do not share an adapted version at all.

## IF THE LICENSE IS SHAREALIKE

Your adaptation must use the same license. Check compatibility before combining works under different licenses.

## IF THE LICENSE IS NONCOMMERCIAL

Do not use it in a commercial context. “Commercial” is fact-specific; when in doubt, ask the creator or choose a different work.

## KEEP A RECORD

Save the source URL, the license URL, the author name, and the date you accessed it. Future you will need it.
